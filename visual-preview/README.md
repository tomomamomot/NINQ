# NINQ 見た目の比較

現在のカレンダー配置を活かした「現在風」と「改善案」の比較。現在風は雰囲気の再現であり、本番画面の完全な複製ではありません。

2026年9月の架空データを固定で表示。28日の強調もサンプルです。月移動、日別詳細、期間付き予定の追加・編集・削除、会社登録が可能。案の切り替えでは入力内容を保持し、再読み込みで初期化します。

本番のコード・保存領域・同期・認証を使用せず、すべてメモリー内で動作します。画面上の同期済み表示は見本です。売上は簡略化した税抜額で、請負は日額、それ以外は人工×単価を対象日数分集計します。本番の帳票計算として使用しないでください。

独自の visual-* 資産を使用（CSS v2、JavaScript v1）。既存の親PWAが資産をキャッシュする可能性があるため、今後の更新ではファイル名とHTMLの参照を一緒に変更します。この試作自身はPWAを登録しません。

検証: `node --test tests/visual-preview.test.cjs`。本番ファイルや前回の design-preview は変更しません。

2026-09-28 検証結果: 関連テスト全47件成功。ブラウザーで360・390・430・1440pxの両案のカレンダー・集計・予定入力、および会社登録の横幅を確認。9月28日の3予定の一覧、予定追加（0.5人工で12,500円加算）、案切り替え後の保持、削除で元の集計に戻ること、会社追加、月移動を確認。コンソールエラーなし。改善案の主要な文字色と背景色の組み合わせは4.5:1以上。主要ボタンは44px以上、密度を保つカレンダー内の日付・予定帯は例外で、日付から大きな詳細画面を開けます。Android・iPhoneの実機操作は未確認です。
