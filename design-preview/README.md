# NINQ デザイン比較用の試作

`index.html` をHTTPサーバーで開くと、3案を切り替えて操作できます。使用データは架空です。

予定の追加・編集・削除、会社登録、月移動、請求書見本に対応。データはJavaScriptのメモリー内だけに保持し、再読み込みで初期状態に戻ります。本番コードの読み込み、ログイン、クラウド同期、ストレージへの読み書き、Service Worker登録は行いません。

試作独自の `preview-*-v1` ファイル名を使用しています。更新時はHTMLの参照先と資産ファイル名を合わせて変更してください。同じオリジンの既存PWAが試作資産もキャッシュする場合があるためです。

試作の請求計算は人工・残業に10%の税額を加えてから経費を加算する月末締めの見本です。実際の請求書発行はありません。

検証：`node --test tests/design-preview.test.cjs`
